# Frontline — Sürümler

**Frontline**, harita üzerinde cephe hareketleri, işgal animasyonları, taktik oklar,
yazı katmanları ve portre/rozetlerle belgesel tarzı video üreten bir masaüstü uygulamasıdır.

## İndirme

Kurulum dosyaları sağdaki **Releases** bölümündedir.

| Dosya | Açıklama |
| --- | --- |
| `Frontline-<sürüm>-Kurulum.exe` | Normal kurulum (Başlat menüsü kısayolu, `.fline` dosya ilişkilendirmesi) |
| `Frontline-<sürüm>-Tasinabilir.exe` | Kurulum gerektirmeyen tek dosya |

## Lisans

Uygulama **lisanslıdır ve yalnızca izin verilen bilgisayarlarda çalışır.**
İlk açılışta bilgisayarınıza özel bir kimlik (`FL-...`) gösterilir; bu kimliği
uygulamanın sahibine ileterek lisans alabilirsiniz. Lisans yalnızca o bilgisayarda
geçerlidir.

Bu depo yalnızca dağıtım içindir; kaynak kodu içermez.
